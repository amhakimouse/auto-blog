# Database Models

All models live in `backend/app/models/`.  
Base class: `app.database.Base` (SQLAlchemy `DeclarativeBase`).  
All PKs are `UUID` generated by `gen_random_uuid()` server-side.

---

## User (`users`)

**File:** `models/user.py`

| Column | Type | Notes |
|---|---|---|
| `id` | UUID PK | |
| `email` | VARCHAR(320) UNIQUE | login identifier |
| `hashed_password` | VARCHAR(255) | bcrypt hash |
| `full_name` | VARCHAR(255) | nullable |
| `is_active` | BOOLEAN | default True |
| `is_superuser` | BOOLEAN | default False |
| `is_verified` | BOOLEAN | email verification |
| `plan` | VARCHAR(50) | e.g. free, pro, enterprise |
| `credits` | INTEGER | decremented on job completion |
| `created_at` | TIMESTAMPTZ | |
| `updated_at` | TIMESTAMPTZ | |

**Relationships:** `jobs` (1:N), `articles` (1:N), `integrations` (1:N)

---

## Integration (`integrations`)

**File:** `models/integration.py`  
Represents a **WordPress site / brand profile** owned by a user.

| Column | Type | Notes |
|---|---|---|
| `id` | UUID PK | |
| `user_id` | UUID FK → users | CASCADE delete |
| `name` | VARCHAR(255) | display name |
| `wp_url` | VARCHAR(2048) | WordPress site URL |
| `wp_username` | VARCHAR(255) | WP Application Password username |
| `wp_password` | TEXT | Fernet-encrypted |
| `is_active` | BOOLEAN | default True |
| `existing_post_links` | JSONB | `{slug: url}` map, populated by `sync_wp_links` task |
| `created_at` | TIMESTAMPTZ | |
| `updated_at` | TIMESTAMPTZ | |

**Relationships:** `owner` (User), `jobs` (1:N), `articles` (1:N)

---

## Job (`jobs`)

**File:** `models/job.py`  
One unit of work. Created by API, processed by Celery worker.

| Column | Type | Notes |
|---|---|---|
| `id` | UUID PK | |
| `user_id` | UUID FK → users | CASCADE delete |
| `integration_id` | UUID FK → integrations | nullable, SET NULL on delete |
| `workflow_type` | VARCHAR(50) | `keyword_to_article` \| `reference_to_article` |
| `input_keyword` | VARCHAR(500) | Workflow 1 input |
| `input_url` | VARCHAR(2048) | Workflow 2 input, SSRF-validated |
| `status` | VARCHAR(20) | enum-like: pending/processing/completed/failed + granular |
| `progress_pct` | INTEGER | 0-100, updated by worker stages |
| `error_message` | TEXT | populated on failure (capped at 2000 chars) |
| `celery_task_id` | VARCHAR(255) | for task revocation |
| `meta` | JSONB | flexible bag: scraped_urls, gap_analysis, etc. |
| `created_at` | TIMESTAMPTZ | |
| `updated_at` | TIMESTAMPTZ | |
| `completed_at` | TIMESTAMPTZ | nullable |

**Enums:**  
`JobStatus`: `pending`, `processing`, `completed`, `failed`  
`WorkflowType`: `keyword_to_article`, `reference_to_article`

**Granular status strings** (set during processing, not in enum):  
`searching`, `scraping`, `analyzing`, `outlining`, `writing`

**Relationships:** `owner` (User), `integration` (Integration), `article` (1:1)

---

## Article (`articles`)

**File:** `models/article.py`  
The final generated content. 1:1 with Job (cascade deletes).

| Column | Type | Notes |
|---|---|---|
| `id` | UUID PK | |
| `job_id` | UUID FK → jobs | UNIQUE (1:1), CASCADE delete |
| `user_id` | UUID FK → users | CASCADE delete |
| `integration_id` | UUID FK → integrations | nullable, SET NULL |
| `article_status` | VARCHAR(30) | `draft_ready` / `scheduled` / `published` / `publish_failed` |
| `title` | VARCHAR(500) | |
| `slug` | VARCHAR(600) | UNIQUE, nullable |
| `html_content` | TEXT | bleach-sanitised HTML |
| `plain_text` | TEXT | nullable, for scoring |
| `word_count` | INTEGER | |
| `meta_description` | VARCHAR(1000) | SEO meta |
| `focus_keyword` | VARCHAR(255) | primary target keyword |
| `tags` | ARRAY(VARCHAR) | semantic keywords, max 10 |
| `images` | JSONB | list of `{role, base64_image, alt_text, mime_type}` |
| `featured_image_url` | VARCHAR(2048) | nullable, WP URL after publish |
| `wp_post_id` | INTEGER | nullable, set after WP publish |
| `wp_post_url` | VARCHAR(2048) | nullable |
| `scheduled_publish_at` | TIMESTAMPTZ | nullable |
| `published_at` | TIMESTAMPTZ | nullable |
| `source_urls` | JSONB | list of scraped competitor URLs |
| `created_at` | TIMESTAMPTZ | |
| `updated_at` | TIMESTAMPTZ | |

**ArticleStatus constants** (plain strings, not a PG ENUM):  
`draft_ready`, `scheduled`, `published`, `publish_failed`

**Relationships:** `job` (Job), `integration` (Integration)
